## ?? Workflow utilisateur

### Scénario 1: Ajouter un périphérique physique

```
1. User clique "Ajouter périphérique" sur ESP32-Bureau-101
   ?
2. Dialog ? Remplir:
   - Nom: temp_sensor_room
   - Type: temperature
   - GPIO: 32
   - Unité: °C
   ?
3. Clic "Ajouter"
   ?
4. API POST /api/Devices/esp32-bureau-101/peripherals
   ?
5. Backend met à jour les Desired Properties du Twin
   ?
6. IoT Hub notifie l'ESP32
   ?
7. ESP32 configure le GPIO 32 comme capteur température
   ?
8. ESP32 publie l'état dans Reported Properties
   ?
9. Interface rafraîchit et affiche le nouveau périphérique ?
```

### Scénario 2: Contrôler un relais

```
1. User clique sur icône "? turn-on" du périphérique "relay1"
   ?
2. API POST /api/Devices/esp32-bureau-101/peripherals/relay1/commands/turn-on
   ?
3. Backend invoque méthode directe IoT Hub: "peripheralCommand"
   ?
4. ESP32 reçoit la commande
   ?
5. ESP32 exécute: digitalWrite(GPIO_33, HIGH)
   ?
6. ESP32 met à jour Reported: { "state": "on" }
   ?
7. Interface rafraîchit après 1s et affiche l'état ON ?
```
